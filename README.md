# HRyUp - Virtual HR Support Platform

HRyUp is a virtual Human Resource support service tailored for micro, small, and medium enterprises (MSMEs) in Las Piñas City. This multi-tenant Django platform centralizes 6 core HR functions:
1. Recruitment Assistance
2. Onboarding Support
3. 201 Files / Employee Records
4. Attendance & Leave Management
5. Payroll Assistance (Data Compilation)
6. HR Helpdesk & Templates

## Features
- Strict Tenant Data Isolation (no cross-company data leakage).
- Role-Based Access Control (Admin, Staff, Client Manager, Client Employee).
- Comprehensive Audit Logging.
- Responsive, Mobile-First Bootstrap 5 UI.

## Local Setup Instructions

1. **Clone and create a virtual environment:**
   ```bash
   git clone <repo-url> hryup
   cd hryup
   python -m venv venv
   # Activate it (Windows)
   .\venv\Scripts\activate
   # Activate it (Mac/Linux)
   source venv/bin/activate
   ```

2. **Install requirements:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Environment Variables:**
   Copy `.env.example` to `.env` and update the keys (especially `SECRET_KEY`).
   ```bash
   cp .env.example .env
   ```

4. **Migrate and Seed Data:**
   ```bash
   python manage.py migrate
   # Seed the database with demo companies, packages, and roles
   python manage.py seed_demo
   ```

5. **Run the Server:**
   ```bash
   python manage.py runserver
   ```
   Visit `http://localhost:8000`. You can log in using the accounts generated by the `seed_demo` script (e.g., `admin@hryup.ph`, `manager@alphatech.example.com` / Password: `password123!`).

## Deployment (Render Web Service)

1. Connect your GitHub repository to [Render.com](https://render.com).
2. Create a new **Web Service** and a new **PostgreSQL Database**.
3. **Build Command:** `./build.sh`
4. **Start Command:** `gunicorn hryup.wsgi:application`
5. **Environment Variables:**
   - `DJANGO_SETTINGS_MODULE`: `hryup.settings.prod`
   - `DATABASE_URL`: (Copy from the Neon or Render Postgres connection string)
   - `SECRET_KEY`: (Generate a long random string)
   - `ALLOWED_HOSTS`: `<your-app-name>.onrender.com`
   - `CLOUDINARY_URL` / keys (if using Cloudinary for media storage).

## Database Restoration Guide

To restore the database from a JSON backup generated by `backup_db`:
1. Ensure your target database is migrated to the latest schema (`python manage.py migrate`).
2. Run the restore command:
   ```bash
   python manage.py restore_db path/to/backup.json
   ```
   *Warning: This flushes the existing database before loading the backup data.*

## Recommended Next Steps for Production
1. **NPC Registration:** Register the data processing system with the National Privacy Commission (NPC) of the Philippines.
2. **Two-Factor Authentication (2FA):** Implement TOTP (Time-based One-Time Password) for `HRYUP_ADMIN` and `HRYUP_STAFF` accounts for heightened security on client data.
3. **Paid Hosting & Backups:** Ensure the PostgreSQL database has automated daily snapshots enabled (e.g., AWS RDS or Render paid tier) before migrating real client data.
4. **Email Infrastructure:** Configure a production SMTP provider (like SendGrid or AWS SES) in `.env` to ensure notification emails are delivered reliably.
